# CRM de Leads

Sistema web desenvolvido para captura e gerenciamento de leads de empresas.

O projeto possui um assistente de atendimento que coleta informações de potenciais clientes e envia os dados para um painel administrativo protegido por login.

## 🚀 Funcionalidades

* Captura de leads através de chat
* Nome, WhatsApp e interesse do cliente
* Painel administrativo
* Login protegido por sessão
* Logout
* Banco de dados PostgreSQL
* Alteração de status dos leads
* Status: Novo, Em atendimento, Venda fechada e Perdido
* Observações por cliente
* Busca por nome, WhatsApp ou interesse
* Filtro por status
* Contadores no dashboard
* Acesso direto ao WhatsApp do cliente
* Layout responsivo
* Aplicação hospedada online

## 📌 Objetivo do projeto

O objetivo é facilitar o atendimento de empresas, permitindo capturar potenciais clientes automaticamente e organizar o acompanhamento comercial em um único painel.

Este projeto também faz parte do meu aprendizado em desenvolvimento web, backend, APIs, banco de dados e criação de sistemas para empresas.
